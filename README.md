# Sonoran Social (workshop marketing site)

Marketing site for a Phoenix social media agency focused on housecleaning businesses. Built with [Next.js](https://nextjs.org) 16 (App Router), TypeScript, and Tailwind CSS v4.

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm run start
```

Site copy lives in `src/lib/site-content.ts` and `src/lib/site-config.ts`.

## Deploy

Deploy on [Vercel](https://vercel.com/new) or any Node host that supports Next.js. Set `NEXT_PUBLIC_SITE_URL` to your production URL for correct Open Graph links.
